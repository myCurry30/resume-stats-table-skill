# 数据 JSON 结构（data.json）

`build_next_year.py` 需要的 data.json 顶层含 `candidates`（候选人数组）与可选的 `column_map`。

## column_map（主 sheet 个人信息列 → Excel 列号）

以下为「杭州岗」类主 sheet 的典型映射，按本 skill 捕捉的模板为准；若实际模板列不同，据此调整：

| 字段名 | 列 | 类型 | 说明 |
|---|---|---|---|
| 序号 | B | int | 自动 1..N，可省略由脚本按顺序填 |
| 姓名 | C | str | 必填 |
| 性别 | D | str/null | 简历未标注则 null（留空） |
| 出生年份 | E | int/null | 简历未标注则 null |
| 联系方式 | F | int(手机) | 手机号去横杠/空格 |
| 本科学校 | G | str | |
| 本科专业 | H | str | |
| 硕士学校 | I | str | 校名规范（用全称，可含(武汉)等标注） |
| 硕士专业 | J | str | |
| 院校类别 | K | str | 985/211/双一流/普通院校/QS xx |
| 意向城市 | L | str | 岗位城市，如「杭州」 |

面试相关列（M 笔试结果, N 面试时间, O 面试记录, P 面试得分, Q 面试结果, R 面试批次, S 备注）
对新一届候选人一律留空，脚本会自动为未使用列留空。

## 示例

```json
{
  "column_map": {
    "姓名": "C", "性别": "D", "出生年份": "E", "联系方式": "F",
    "本科学校": "G", "本科专业": "H", "硕士学校": "I", "硕士专业": "J",
    "院校类别": "K", "意向城市": "L"
  },
  "candidates": [
    {"姓名": "陈涛", "性别": null, "出生年份": 2002, "联系方式": 13488202106,
     "本科学校": "哈尔滨工业大学", "本科专业": "光电信息科学与工程",
     "硕士学校": "中国科学技术大学", "硕士专业": "电子信息（光学工程）",
     "院校类别": "985", "意向城市": "杭州"}
  ]
}
```

## 字段提取原则
- **不要臆测简历未写的信息**：性别、出生年份等缺失 → `null`（留空），并向用户列出待确认清单。
- 出生年份由「年龄/毕业年」推算的，提示可能 ±1 年。
- 院校类别按**硕士学校**判断，可参考模板自带的「211&985院校名单」sheet；双一流重点校标注「双一流」。
- 联系方式取手机号，去除 `+86`、横杠、空格。
