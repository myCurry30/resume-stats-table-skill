# 校招统计表主 sheet 典型列与取值规范

以下根据实际模板「杭州岗」sheet 归纳，供模型在解析简历、填充时参考。实际以
`read_template.py` 输出的模板 dump 为准（列位置可能随届次变化）。

## 主 sheet（如「杭州岗」）典型列

| 列 | 含义 | 填法 |
|---|---|---|
| B | 序号 | 整数 1..N |
| C | 姓名 | 简历姓名 |
| D | 性别 | 男/女；未标注留空 |
| E | 出生年份 | 4 位年；未标注留空 |
| F | 联系方式 | 11 位手机号（去横杠/空格/+86） |
| G | 本科学校 | 全称规范（如"中国地质大学(武汉)"） |
| H | 本科专业 | |
| I | 硕士学校 | 全称规范 |
| J | 硕士专业 | |
| K | 院校类别 | 985 / 211 / 双一流 / 普通院校 / QS 排名（如"QS 77"） |
| L | 意向城市 | 岗位城市（如"杭州"） |
| M–S | 笔试/面试 各列 | 新一届候选人留空，待面试流程填 |

## 院校类别判断
- 用**硕士学校**定级。
- 985：39 所 985 高校（清华、北大、中科大、哈工大、复旦、上交、浙大、华科、东南、武大、大连理工、
  电子科大、中山、东南、华东师范、南开、天大、北理工、川大、西交、兰大、东北大学、同济、中南、厦大、
  南大、湖大、人大、吉大、重庆、华南理工、北航、中农、国防科大、西农、中央民族、中海洋、山大、西北工大 等）。
- 211：纳入 211 工程（含上述 985），如武汉理工、合肥工业、西电、南昌大学、郑州大学、湖南师范、华东理工、
  西南交大、中国地质大学(武汉)、大连海事 等。
- 双一流：非 985/211 但进入"双一流"名单的重点高校（如中国科学院大学、南京邮电大学、湘潭大学、西北大学 等），
  参照模板既有标注使用「双一流」。
- 普通院校：未入选上述名单。
- 海外院校用 QS 排名，如"QS 77"。

注：本 skill 配套模板自带「211&985院校名单」sheet，可交叉核对。

## 姓名/字段规范
- 姓名去掉多余空格；学历段分别填本科/硕士，若简历只有本科（本硕同一学校等）也照实填。
- 专业名称尽量照简历原文。
- 简历未明确的信息（性别/出生年份）**不要猜**，留空并列入待确认清单交给用户。
